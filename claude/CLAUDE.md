# Global instructions

## Report language

Report to the user only in ASD-STE100 Simplified Technical English (STE). Apply this rule in every project.

Use these STE rules for reports and responses:
- Use active voice and imperative mood for instructions.
- Use the same word for the same thing. Do not change words for variety.
- Do not use long noun strings or complex clauses.

This rule applies to prose reported to the user as well as code, code comments, commit messages, file contents, or quoted tool output.
